# 共用記帳小本本

宇群 & 廷璇 的共用記帳小工具。手機打開網址 →「加入主畫面」就像 App 一樣用。

## 功能
- 記一筆：誰付、金額、平分 / 全額幫墊、備註、日期
- 首頁大字顯示「目前誰欠誰多少」
- 明細列表（點一筆可刪除）
- 一鍵結清歸零（舊記錄保留在雲端）
- 可切換主題（🖤 死亡筆記本 / 🔮 小魔女DoReMi / 🤍 奶霧 / 💜 薰衣草霧），每人記住自己的
- 兩支手機即時同步

## 技術
- 單一 `index.html`，純前端，字型已內嵌。
- 資料存 Supabase（專案 `ace211188's Project`，資料表 `ledger_entries`）。
- 部署在 GitHub Pages。
